# Definition of Done (Когда задача считается выполненной)
Задача считается полностью завершенной, только если выполнены ВСЕ пункты:
1. Код написан и работает локально.
2. Написаны или обновлены тесты в `tests/`, покрывающие новое поведение.
3. Команда `pytest` завершается успешно (все тесты зеленые).
4. Обновлен файл `docs/ai/PROGRESS.md` (что сделано, что дальше).
5. Если принималось архитектурное решение — оно записано в `docs/ai/DECISIONS.md`.
6. Выполнены требования из `security.md` (нет XSS, SQL-инъекций и т.д.).
