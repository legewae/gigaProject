# Безопасность (Критично!)
- **Пароли:** Только хэширование через `argon2`. Запрещено хранить пароли в открытом виде или использовать md5/sha1.
- **XSS (HTML):** Любой Markdown, введенный пользователем, должен проходить через парсер `markdown` и **обязательно** очищаться через `nh3` перед сохранением или отображением. Вызов `Markup()` без очистки запрещен.
- **SQL-инъекции:** Только параметризованные запросы. Запрещено склеивать SQL-строки через f-strings или конкатенацию с пользовательским вводом.
- **Секреты:** Все ключи (SECRET_KEY, пароли БД) берутся только из `os.environ` (переменных окружения). Запрещено хардкодить секреты в коде.
- **Доступ:** Проверка прав (admin/editor/reader) должна происходить на бэкенде (в FastAPI), а не только скрытием кнопок в HTML.
