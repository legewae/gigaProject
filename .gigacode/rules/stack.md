# Технологический стек и архитектура
- **Backend:** Python 3.11+, FastAPI.
- **База данных:** SQLite. Файл БД должен лежать в `data/miniwiki.db` (папка монтируется через Docker volume).
- **Frontend:** Jinja2 + HTMX. Не используем vue.js или react, т.к. это лишние зависимости.
- **Markdown:** библиотека `markdown` + очистка `nh3`.
- **Тесты:** pytest + httpx. Все тесты лежат в `tests/`.
- **Структура:**
    - `app/` — код приложения (main.py, роутеры, модели, шаблоны).
    - `tests/` — тесты.
    - `docs/ai/` — память агента.
- **Зависимости:** Запрещено добавлять новые библиотеки в `requirements.txt` без предварительной записи обоснования в `docs/ai/DECISIONS.md`.
- **Язык кода:** переменные и функции на английском, комментарии и документация — на русском.
