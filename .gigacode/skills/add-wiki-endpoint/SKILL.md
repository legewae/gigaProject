# Add wiki endpoint

Когда пользователь просит добавить новый эндпоинт (например, для поиска или тегов):
1. Открой `references/api-conventions.md` — там описаны стандарты именования и ответов.
2. Добавь роут в соответствующий файл в `app/routers/`.
3. Если нужны новые поля в БД, обнови схему в `app/database.py`.
4. Обязательно напиши тест в `tests/` на этот новый эндпоинт (успех + 404/400).
5. Запусти `pytest`.
6. Обнови `docs/ai/PROGRESS.md`.
