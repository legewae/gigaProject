# API Conventions (Стандарты API)

- **Пути:** Всегда используем множественное число (`/pages`, `/search`). Иерархические пути через `/{path:path}`.
- **Методы:** GET для чтения, POST для создания/изменения, DELETE для удаления.
- **Коды ответов:**
    - 200 OK — успешный GET или POST.
    - 303 See Other — успешный POST с редиректом (для HTML-форм).
    - 400 Bad Request — неверные данные.
    - 404 Not Found — страница не найдена.
    - 409 Conflict — дубликат пути.
- **HTML vs JSON:** Если запрос идет от HTMX (заголовок `HX-Request`), возвращаем HTML-фрагмент. Если это API, возвращаем JSON.
