# Security Review

## Когда применять
- Перед каждым коммитом в спринтах с аутентификацией/ролями
- При добавлении новых эндпоинтов, работающих с БД или HTML
- При ревью шаблонов Jinja2

## Как применять
1. Запусти скрипт: `python .gigacode/skills/security-review/scripts/grep_dangerous.py`
2. Разбери каждое срабатывание по чеклисту ниже
3. Для найденных проблем — исправь и добавь регрессионный тест

## Чеклист
- [ ] Все пользовательские строки, попадающие в HTML, проходят `nh3.clean()` при рендере
- [ ] SQL-запросы параметризованы (`?`), нет f-строк с пользовательским вводом
- [ ] Пароли хешируются argon2/bcrypt, не хранятся в открытом виде
- [ ] Секреты только из `os.environ`, нет хардкода
- [ ] Каждый мутирующий эндпоинт проверяет роль (admin/editor)
- [ ] reader видит только страницы с тегом `public`
- [ ] Jinja2: нет `|safe` на пользовательских данных
