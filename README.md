# gigaProject

Упрощённый аналог Wiki.js — вики-платформа с поддержкой Markdown, иерархической навигацией, поиском, ролями и экспортом страниц.

Проект разработан в рамках домашнего задания по курсу «Агентские харнессы» (ОмГТУ, каф. ПМиФИ).

## Быстрый старт

Приложение запускается одной командой (требуется установленный Docker):

```bash
docker compose up --build
```

После сборки приложение будет доступно по адресу: http://localhost:8000
