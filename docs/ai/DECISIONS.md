# Решения по проекту

## [Спринт 0] Выбор стека технологий
- **Backend:** FastAPI (Python 3.11+) — быстрый, современный, автодокументация
- **База данных:** SQLite (файл `data/miniwiki.db`) — простота для MVP, без внешних сервисов
- **ORM:** Отказ от SQLAlchemy — прямые параметризованные запросы через `sqlite3`
- **Frontend:** Jinja2 + HTMX — лёгкость, без тяжёлых JS-фреймворков
- **Markdown:** `markdown` + `nh3` — рендеринг с защитой от XSS
- **Аутентификация:** `argon2-cffi` — стандарт индустрии для хэширования паролей
- **Тесты:** `pytest` + `httpx` — стандарт для FastAPI-проектов
- **Запуск:** Docker Compose — воспроизводимое окружение
