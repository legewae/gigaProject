# MiniWiki

## 1. Описание продукта
Упрощённый аналог Wiki.js (вики-платформа).
Функционал MVP:
- Страницы с иерархическими путями (например, `/docs/nlp`).
- Markdown-редактор с предпросмотром.
- Аутентификация (роли: admin, editor, reader).
- Поиск, теги, дерево навигации.
- Экспорт всех страниц в `.md` (только для admin).
- Задокументированный REST API.

## 2. Технологический стек
- **Backend:** Python 3.11+, FastAPI.
- **База данных:** SQLite (через встроенный модуль `sqlite3`). Файл БД: `data/miniwiki.db`. Запрещено использовать SQLAlchemy.
- **Frontend:** Jinja2 + HTMX. Никаких тяжелых JS-фреймворков (Vue/React).
- **Markdown:** `markdown` + `nh3` (обязательная очистка HTML от XSS).
- **Аутентификация:** `argon2` для хэширования паролей.
- **Тесты:** `pytest` + `httpx`.
- **Запуск:** Docker Compose (`docker compose up --build`).

## 3. Структура каталогов
- `app/` — исходный код FastAPI.
    - `app/main.py` — точка входа.
    - `app/database.py` — подключение к SQLite и инициализация таблиц.
    - `app/crud.py` — функции работы с БД.
    - `app/routers/` — API-роутеры (pages.py, auth.py и т.д.).
    - `app/templates/` — HTML-шаблоны Jinja2.
    - `app/static/` — CSS/JS.
- `tests/` — тесты (pytest).
- `docs/ai/` — контекстная память агента.
- `docs/img/` — скриншоты для отчёта.
- `.gigacode/` — правила и навыки (харнесс).

## 4. Принципы разработки
- Сначала Plan, потом Agent.
- Никаких новых библиотек без записи в `DECISIONS.md`.
- Весь пользовательский HTML очищается через `nh3`.
- SQL только параметризованный.
